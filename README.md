# ratsakatika.com

Hand-written static site, served by GitHub Pages from the root of this branch.

- `index.html` — the whole site (one page)
- `css/style.css` — styles; `css/fonts.css` — self-hosted fonts (Newsreader, Source Sans 3, from Fontsource)
- `img/` — photographs and the paper figure, resized for the web
- `video/` — the clip that plays over the map (on hover, or while in view on touch screens), in four widths; the master it was cut from is kept out of git
- `404.html` and the `projects/`, `cv/`, `publications/`… folders — redirects from the old site's addresses
- `CNAME` — custom domain; `.nojekyll` — tells GitHub Pages not to run Jekyll
